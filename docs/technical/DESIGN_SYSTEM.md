# Дизайн-система

Редизайн 17.08.2026. Источник правды — `packages/ui`. Пять приложений
(`client`, `master`, `operator`, `site`, `web`) используют один набор токенов и
один набор компонентов.

Направление: **Flat Design + Accessible & Ethical**. Палитра — Trust Blue
(платформа) + Safety Orange (срочный режим) + холодный серый.

> Предыдущая палитра (60/30/10, утверждена 19.07.2026) заменена по решению
> владельца продукта. Она проваливала WCAG AA в четырёх местах — см. «Что было
> сломано».

## Как подключается

```css
/* app/globals.css любого приложения */
@import "tailwindcss";
@import "@masterqala/ui/tokens.css";
@import "@masterqala/ui/base.css";

@source "../app";
@source "../components";
@source "../../../packages/ui/src";   /* ← обязательно */
```

Последняя строка не косметика: Tailwind собирает классы только из каталогов,
перечисленных в `@source`. Без неё классы, использованные внутри компонентов
`@masterqala/ui`, не попадут в CSS приложения, и общие компоненты приедут без
стилей. До редизайна этой строки не было ни в одном Next-приложении.

Пакет отдаётся **исходниками** (`exports` → `src/index.ts`), а не сборкой:
нет устаревшего `dist/`, не нужен порядок сборки. Взамен Next-приложения
объявляют `transpilePackages: ['@masterqala/ui']`.

## Цвет

Все значения проверены счётом. Проверка живёт в
`packages/ui/scripts/check-contrast.py` и запускается в CI:

```bash
pnpm --filter @masterqala/ui check:contrast
```

43 пары, пороги: текст ≥ 4.5:1 (WCAG 1.4.3), границы контролов ≥ 3:1 (1.4.11).
Меняя цвет — прогоните проверку. Она существует потому, что на глаз это не
видно: прошлая палитра прошла два ревью с четырьмя провалами.

|---|---|---|---|

| Поверхность | `--color-surface` | `#FFFFFF` | — |
| Утопленная поверхность | `--color-surface-sunken` | `#F1F5F9` | — |

Плюс к каждому семантическому цвету — `-soft` (подложка) и `-ink` (текст на
подложке), а к плотным заливкам — `--color-on-*` для текста поверх.

**Оранжевый означает срочность.** Он маркирует только режим «Сейчас»: кнопку
вызова, бейдж срочной заявки, таймер волны. Использовать его как «ещё один
яркий цвет» нельзя — это лишит его смысла.

## Типографика

Manrope, самохост из `packages/ui/fonts` (субсеты woff2 с `unicode-range` под
кириллицу и латиницу), подключается в `base.css`.

Шкала вместо произвольных значений. `text-[17px]` и подобное больше не пишем:

| Токен | Размер | Назначение |
|---|---|---|
| `text-2xs` | 12px | **низ шкалы** — бейджи, заголовки столбцов, метки |
| `text-xs` | 13px | подписи, вспомогательный текст |
| `text-sm` | 14px | плотные списки, таблицы |
| `text-base` | 16px | **основной текст** |
| `text-lg` … `text-5xl` | 18–48px | заголовки |

12px — жёсткий минимум. Ниже текст перестаёт читаться пользователями со
слабым зрением.

## Движение

`--duration-fast` 140ms (наведение, нажатие) · `--duration-base` 200ms (смена
состояния) · `--duration-slow` 300ms (панели). Одна длительность на все
переходы — антипаттерн.

`prefers-reduced-motion` обрабатывается глобально в `base.css`: переходы
гасятся, декоративные `animate-ping`/`animate-pulse` отключаются, а спиннер
загрузки **замедляется, но остаётся** — он несёт информацию «система занята».

## Фокус

Обводка 3px `--color-primary` с отступом 2px задана в `base.css` для
`:focus-visible` **вне `@layer`**. Неслоёные правила в каскаде сильнее слоёных,
поэтому обводка перебивает утилиту `outline-none`. Проверено в браузере:
элемент с классом `outline-none` получает `outline-style: solid`.

Практический смысл: даже если в коде снова появится `outline-none`, фокус
останется видимым. Но писать `outline-none` всё равно не нужно.

## Компоненты

Импорт из `@masterqala/ui`.

| Компонент | Зачем |
|---|---|
| `Button` | `variant`: primary · urgent · secondary · ghost · danger · success. `loading` даёт спиннер + `aria-busy`. Минимум 44px. |
| `IconButton` | Кнопка-иконка. **`label` обязателен** — иначе у неё нет доступного имени. 44×44. |
| `Input` / `Textarea` / `Select` | **`label` обязателен.** Ошибка через `error` встаёт у поля и связывается `aria-describedby` + `role="alert"`. |
| `Field` / `useFieldIds` | Обвязка для своих контролов. |
| `ErrorSummary` | Сводка ошибок в начале длинной формы, забирает фокус. Дополняет, не заменяет ошибки у полей. |
| `Table` | Настоящая `<table>` с `<th scope="col">` и обязательным `caption`. `hideBelow` убирает столбец на узком экране. Прокрутка внутри контейнера. |
| `Card`, `Badge`, `Alert`, `EmptyState` | `Badge` — `text-2xs`, `nowrap`. `Alert` даёт `role="alert"` для ошибок и всегда иконку рядом с цветом. |
| `Skeleton` / `SkeletonList` | Заглушки загрузки вместо строки «Загрузка…». `SkeletonList` объявляет занятость один раз. |
| `Spinner` | `label` — если стоит без текста рядом. |
| Иконки | ~40 SVG, обводка, 24×24, `currentColor`. |

### Эмодзи в интерфейсе не используются

Было 62 эмодзи в роли иконок. Они по-разному рисуются на разных ОС, не
наследуют цвет, не масштабируются под кегль и озвучиваются скринридером не тем,
что значат. Замена — набор из `@masterqala/ui`.

Для понимания, почему система устроена именно так.

| Дефект | Было |
|---|---|
| Обводка фокуса убрана без замены | 32 `outline-none`, 0 `focus-visible` |
| Кнопки-иконки без доступного имени | 125 `<button>`, 0 `aria-label` |
| Placeholder вместо подписи | 0 `<label>` в `master`/`operator` |
| …и placeholder нечитаем | `--color-muted` 2.44:1 |
| Границы полей почти невидимы | `--color-border` 1.51:1 |
| Белый текст на кнопке успеха | 3.77:1 |
| Вторичный текст | 4.19:1 на фоне |
| Текст ниже минимума | 47 использований 10–11px |
| Произвольная типографика | 92 `text-[Npx]`, 9 размеров |
| Нет адаптивности | 0 `md:`/`lg:`/`sm:` в четырёх приложениях |
| Мгновенная смена состояний | 6 `transition` на четыре приложения |
| Движение без учёта настроек | 0 `prefers-reduced-motion` |
| Шрифт не загружался | 4 приложения молча падали на `system-ui` |
| Таблицы не таблицы | `<div className="grid">` без `<th>` |
