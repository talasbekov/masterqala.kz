# Документация MasterQala.kz

Документы разделены по **скорости устаревания**. Продуктовые решения живут годами,
описание кода меняется с каждым коммитом, статус реализации — с каждым этапом.
Смешивать их в одном файле нельзя: одно изменение кода делает устаревшим весь документ.

## Карта

| Документ | Отвечает на вопрос | Когда обновлять |
|---|---|---|
| [product/spec.md](product/spec.md) | **Что** система должна делать и **почему** так решили | Только при изменении бизнес-решения |
| [engineering/architecture.md](engineering/architecture.md) | Из чего система собрана и как части общаются | При изменении структуры модулей, очередей, интеграций |
| [engineering/data-model.md](engineering/data-model.md) | Какие сущности хранятся, какие у них состояния | При изменении `schema.prisma` |
| [engineering/api.md](engineering/api.md) | Какие HTTP-эндпоинты есть и кто их может звать | При добавлении/изменении контроллера |
| [engineering/development.md](engineering/development.md) | Как поднять, настроить и проверить локально | При изменении env, скриптов, процедуры запуска |
| [STATUS.md](STATUS.md) | Что уже работает, чего нет, где код расходится со спекой | В конце каждого этапа |
| [research/](research/) | Стратегический анализ на конкретную дату | **Никогда.** Устаревшее не правят — добавляют новый датированный файл |
| [superpowers/](superpowers/) | Как именно делали каждый этап (дизайн-доки и планы) | Пополняется автоматически SDD-циклом |

## Как читать в первый раз

1. [product/spec.md](product/spec.md) §1–§3 — что за продукт и как работают оба режима.
2. [STATUS.md](STATUS.md) — что из этого уже реально работает.
3. [engineering/architecture.md](engineering/architecture.md) — как это устроено в коде.
4. [engineering/development.md](engineering/development.md) — поднять у себя и потрогать.

## Правила

**Спека — источник истины по намерению, код — по поведению.** Если они расходятся,
расхождение попадает в [STATUS.md](STATUS.md) явным пунктом с указанием файла, а не
замалчивается правкой одной из сторон.

**Термины пишутся так, как в коде.** Статус заявки — `SEARCHING`, а не «поиск мастера».
Таблица соответствия русских формулировок спеки и значений enum — в
[engineering/data-model.md](engineering/data-model.md#статусы-заявок).

**`research/` не редактируется.** Это датированные снимки: они ценны именно тем, что
показывают, что было известно на момент решения. Устаревшие утверждения из них
перечислены в шапке самого файла.
