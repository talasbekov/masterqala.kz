# HTTP API

Базовый путь — `/api/v1`. Все пути ниже указаны **без** него.

## Аутентификация и доступ

Вход двухшаговый: запрос кода на телефон → обмен кода на JWT. Токен живёт 30 дней,
передаётся заголовком `Authorization: Bearer <token>` и тем же значением в
`handshake.auth.token` при подключении к WebSocket.

| Уровень | Как обеспечивается | Кто проходит |
|---|---|---|
| Открытый | нет гварда | `/health`, `/auth/*`, `/categories` |
| Авторизованный | `JwtAuthGuard` | любой пользователь с валидным токеном |
| Оператор | `JwtAuthGuard` + `RolesGuard` | только `role === 'OPERATOR'` |

Заблокированный пользователь (`isBlocked`) получает `403` и на `JwtAuthGuard`,
и на `/auth/verify-code` — то есть не может ни работать, ни перевойти.

**Роль «мастер» не проверяется гвардом.** Право мастера на действие проверяет сам
сервис — по наличию `MasterProfile` в статусе `ACTIVE` и по тому, назначен ли он на
эту заявку. Не полагайтесь на гварды при добавлении мастерских эндпоинтов.

## Коды ответов

| Код | Значение в этом API |
|---|---|
| `409` | Гонка: статус объекта уже изменился (типично для `accept`, любых переходов) |
| `403` | Нет прав, либо пользователь заблокирован |
| `404` | Объект не существует **или** не принадлежит вызывающему — сознательно не различаем |
| `400` | Валидация DTO (`ValidationPipe` с `whitelist: true` — лишние поля отбрасываются) |

## Срочные заявки

Клиентские:

| Метод | Путь | Назначение |
|---|---|---|
| `POST` | `/orders/preview` | Расчёт стоимости выезда до создания. Ничего не создаёт и не холдит |
| `POST` | `/orders` | Создать заявку: холд полной стоимости выезда, запуск волн |
| `GET` | `/orders/active` | Текущая активная заявка клиента |
| `GET` | `/orders` | История заявок |
| `GET` | `/orders/:id` | Деталь заявки, включая отзыв, если он оставлен |
| `GET` | `/orders/:id/photos/:photoId` | Фото проблемы. Доступ: клиент, назначенный мастер, оператор |
| `POST` | `/orders/:id/confirm-price` | Принять названную мастером цену работ |
| `POST` | `/orders/:id/reject-price` | Отклонить цену — заявка отменяется, мастер получает компенсацию |
| `POST` | `/orders/:id/confirm-completion` | Подтвердить выполнение → `CLOSED` |
| `POST` | `/orders/:id/cancel` | Отменить. Последствия зависят от статуса |
| `POST` | `/orders/:id/retry-search` | Из `NO_MASTERS` — новый холд и новая попытка поиска |

Мастерские:

| Метод | Путь | Назначение |
|---|---|---|
| `GET` | `/master/active-order` | Заявка, над которой мастер сейчас работает |
| `POST` | `/orders/:id/accept` | Принять оффер. При гонке проигравшие получают `409` |
| `POST` | `/orders/:id/on-way` | «Еду» → `MASTER_ON_WAY` |
| `POST` | `/orders/:id/on-site` | «На месте» → `INSPECTION` |
| `POST` | `/orders/:id/propose-price` | Назвать цену работ и комментарий |
| `POST` | `/orders/:id/complete` | «Выполнено» → `DONE` |
| `POST` | `/orders/:id/cancel` | Отмена после принятия — штраф и возобновление поиска |

## Отзывы и споры

| Метод | Путь | Назначение |
|---|---|---|
| `POST` | `/orders/:id/review` | Оценка 1–5 и комментарий по срочной заявке |
| `POST` | `/planned-orders/:id/review` | То же по плановой |
| `POST` | `/orders/:id/disputes` | Открыть спор. Окно — 48 ч после закрытия |

Открытый спор замораживает авто-закрытие заявки: джоба `order-auto-close` проверяет
наличие спора и не закрывает заявку, пока он не разобран.

## Оператор

Все требуют `role === 'OPERATOR'`.

### Верификация мастеров

| Метод | Путь | Назначение |
|---|---|---|
| `GET` | `/admin/applications?status=PENDING_REVIEW` | Очередь анкет |
| `GET` | `/admin/applications/:id` | Анкета целиком |
| `GET` | `/admin/applications/:id/documents/:docId` | Скачать документ |
| `POST` | `/admin/applications/:id/decision` | `APPROVE` / `REJECT` / `REQUEST_INFO` с комментарием |

### Заявки, мастера, пользователи

| Метод | Путь | Назначение |
|---|---|---|
| `GET` | `/admin/orders?type=urgent\|planned&status=…` | Список заявок обоих типов |
| `GET` | `/admin/orders/:id?type=…` | Деталь заявки |
| `GET` | `/admin/masters?category=…&district=…` | Мастера с производным статусом (учитывает блокировки) |
| `GET` | `/admin/users?search=…` | Поиск по телефону и имени |
| `POST` | `/admin/users/:id/block` | Заблокировать с причиной |
| `POST` | `/admin/users/:id/unblock` | Разблокировать |

Оператор пока **только читает** заявки — вмешаться в чужую заявку (переназначить
мастера, сменить статус) нельзя, см. [STATUS.md](../STATUS.md).

### Споры и выплаты

| Метод | Путь | Назначение |
|---|---|---|
| `GET` | `/admin/disputes?status=OPEN` | Очередь споров |
| `GET` | `/admin/disputes/:id` | Спор с доказательствами и историей заявки |
| `POST` | `/admin/disputes/:id/resolve` | Решение: возврат сбора и/или санкция мастеру + обоснование |
| `GET` | `/admin/withdrawals` | Заявки на вывод средств |

Все действия оператора пишутся в `AuditLog`.
